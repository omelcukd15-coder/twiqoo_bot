# Twiqo Bot 🤖

Telegram-бот для знакомств с системой модерации, оценок и чатов.

## Возможности

- 🔍 Поиск людей по городу и возрасту
- ⭐ Система оценок (1-5)
- ❤️ Взаимные симпатии → открывается чат
- 📝 Редактирование анкеты с повторной модерацией
- 📢 Обязательная подписка на канал после 10 просмотров
- 🛡 Админ-панель с модерацией и рассылкой

## Технологии

- Python 3.11
- Aiogram 3.x
- SQLAlchemy 2.x
- SQLite
- Render (хостинг)
